# Личная CRM

Приложение для своих контактов: кто это, откуда знакомы, телефон, почта, о чём договорились.

## Что нужно установить

- Node.js и pnpm
- Docker Desktop (должен быть запущен: значок кита в верхней панели)

## База данных

База — PostgreSQL, работает в Docker.

**Первый запуск.** Создайте файл `.env` по образцу `.env.example` и заполните значения. Файл `.env` хранит пароль, поэтому он не попадает в git.

**Запустить базу** (из папки проекта):

```
docker compose up -d
```

**Проверить, что работает:**

```
docker compose ps
```

В колонке STATUS должно быть `healthy`.

**Остановить базу:**

```
docker compose down
```

Данные при этом сохраняются. Их удаляет только команда с флагом `-v`, не используйте её без необходимости.

## Приложение

Все команды — из папки проекта, база должна быть запущена.

**Первый запуск:**

```
pnpm install       # скачать библиотеки
pnpm db:migrate    # создать таблицы в базе
pnpm db:seed       # добавить 1000 тестовых контактов (только в пустую базу)
```

`pnpm db:seed` ничего не удаляет: если в базе уже есть контакты, он просто напишет об этом и остановится.

Приложение берёт настройки базы из `.env`: либо `DATABASE_URL`, либо `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` (и, если порт не 5432, `POSTGRES_PORT`) — те же, что использует Docker.

**Запустить:**

```
pnpm build && pnpm start
```

Откройте http://localhost:3000. Остановить — `Ctrl+C` в окне терминала.

Для разработки (страницы обновляются сами при правке кода): `pnpm dev`.

**Проверить код:** `pnpm test` — автоматические проверки, `pnpm lint` — стиль кода.

## Как проверить руками

1. Откройте http://localhost:3000 — виден список всех контактов, сверху их число.
2. «Добавить контакт» → заполните имя (остальное по желанию) → «Сохранить». Вы вернётесь в список, сверху будет «Контакт … добавлен».
3. В поиске начните вводить имя — список сужается на ходу. Регистр не важен, «е» и «ё» считаются одной буквой.
4. Откройте карточку → в «Новая заметка» напишите текст → «Добавить заметку». Заметка появится сверху с датой и временем.
5. Обновите страницу — заметка на месте.
6. Откройте тот же адрес в другом браузере (например, Safari) — там те же контакты и заметки.
